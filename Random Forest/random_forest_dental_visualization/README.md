# Random Forest Dental Visualization Example

This folder contains a complete beginner-friendly Random Forest example for dental treatment prediction.

## Files

1. dental_treatment_data.csv
2. random_forest_dental_visualization.py
3. class_distribution.png
4. confusion_matrix.png
5. feature_importance.png
6. one_decision_tree.png

## How to Run

Install libraries:

```bash
pip install pandas scikit-learn matplotlib
```

Run:

```bash
python random_forest_dental_visualization.py
```

## Important Note

This is an educational dataset only. It should not be used for real medical or dental diagnosis.
